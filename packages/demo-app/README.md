# demo-app

A Vite + React app that renders the example positions and orders from
`@ekubo/position-svg-generator`. The examples in `src/constants/examples.ts` are
also the inputs for the library's snapshot tests.

- `npm run dev` starts the dev server.
- `npm run build` type-checks with TypeScript 7 and builds with Vite.

Lint, format and type-check rules live at the repository root; see the root
`AGENTS.md`.
