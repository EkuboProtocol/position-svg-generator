# Ekubo Position SVG Generator

This repository contains:

1. A library for generating SVG representations of Ekubo Protocol positions
2. A React UI for previewing the SVGs generated by the library

## Repository Structure

- `/src` - The main SVG generator library source code
- `/svg-generator-ui` - A React application that consumes the SVG generator library

## Development

### SVG Generator Library

```bash
# Install dependencies
npm install

# Build the library
npm run build

# Development mode (watch for changes)
npm run dev
```

### SVG Generator UI

```bash
# Set up the UI (install dependencies and link to the local library)
npm run setup:ui

# Run both the library in watch mode and the UI
npm run dev:ui
```

This will:
1. Start the library in watch mode, rebuilding when you make changes to the `generateSvg` function
2. Start the UI development server with hot module reloading
3. Allow you to see changes to the SVG generator immediately reflected in the UI

## How to Use

1. Make changes to the `generateSvg` function in `src/index.ts`
2. The library will automatically rebuild
3. The UI will update to show your changes in real-time
