# Ekubo position SVG Generator

This repository is a small mono repo containing

1. `@ekubo/position-svg-generator` - A typescript library that generates SVGs for Ekubo positions.
2. `demo-app` - A React application demonstrating how to use the library to render various SVGs.

Run `npm install` in the project’s root directory, then run `npm run dev` in both `packages/demo-app` and `packages/position-svg-generator`. This setup lets you modify the function that generates SVGs and see your changes in real time at localhost:5173.
